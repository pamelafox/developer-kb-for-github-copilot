MCP: Model Context Protocol

MCP is the open standard that tells agent runtimes how to discover and connect to the tools they can call.

🔗 MCP specification: modelcontextprotocol.io

MCP architecture

Here, GitHub Copilot is the host; GitHub MCP is a connected server.

Configure GitHub MCP in VS Code

1. Add .vscode/mcp.json

{
  "servers": {
    "github": {
      "type": "http",
      "url": "https://api.githubcopilot.com/mcp/readonly",
      "headers": {
        "X-MCP-Toolsets": "repos,issues,pull_requests,discussions"
      }
    }
  }
}

2. Start and verify

1
Select Start above the server definition.
2
Authorize with the event-provided GitHub account.
3
Confirm the github server is running.
4
Open Copilot Chat tools and find the GitHub tools.

Configure GitHub MCP in Copilot CLI

GitHub MCP is built in with read-only tools enabled by default.

1. Start a new session

Add the Discussions toolset:

copilot --add-github-mcp-toolset discussions

2. Verify the server

From the active Copilot CLI session:

/mcp show github-mcp-server

Confirm tools are available for repositories, issues, pull requests, and discussions.

Configure GitHub MCP in the Copilot App

1. Add the server

1
Open Customize → MCP → Add → MCP Server.
2
Name it github and select HTTP.
3
Add the endpoint and toolset header.

2. Enter the connection details

URL

https://api.githubcopilot.com/mcp/readonly

Header

X-MCP-Toolsets: repos,issues,pull_requests,discussions

Add the server, authorize with the event account, then confirm the GitHub tools appear.

Foundry IQ ingests documents into a search index

A cloud pipeline turns source files into searchable, citable chunks.

🗄️

Blob Storage

Stores a retrievable copy of each source document.

⚙️

Search indexer

Detects additions and updates, then runs the ingestion pipeline.

🧠

Content Understanding

Extracts text, tables, images, structure, and metadata.

🧩

Chunk + vectorize

Creates semantic chunks and computes embeddings.

🔎

Search index

Stores text, vectors, metadata, and source references together.

For this workshop, the ingestion pipeline has already run.

Content Understanding preserves more than plain text

Rich extraction

Reads text and OCR, preserves tables as structured HTML, and describes images and diagrams.

Semantic chunking

Splits on meaningful document boundaries instead of arbitrary character counts.

Grounding metadata

Keeps document identity, page location, and source references with every chunk.

Source document
→
Structured extraction
→
Semantic chunks

Hybrid search improves relevance

Foundry IQ combines exact-term matching with semantic similarity, then reranks the fused results.

QueryWhat are the CSV export requirements?
→
Keyword searchFinds exact terms such as CSV, field names, and identifiers.
Vector searchFinds passages with similar meaning even when wording differs.
→
Reciprocal Rank FusionCombines both ranked result lists.
→
Semantic rerankingPromotes the chunks most relevant to the full question.
