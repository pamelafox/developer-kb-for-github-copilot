1. Purpose and scope

Mapayça Markets is testing product-level sourcing records for a limited specialty-grocery program. Cocoarynth will supply the Ecuador Esmeraldas 72% chocolate bar to the stores named in the pilot order. Each shipment must be accompanied by an Origin Passport export that Mapayça's inventory system can import without manual conversion.

The initial pilot supports one finished production batch per file. A file may therefore contain one header row and one data row. Multi-batch or bulk export is outside the pilot scope and is not an acceptance requirement.

2. Required delivery format

The Mapayça inventory importer accepts CSV files only. JSON uploads are rejected and do not satisfy the pilot requirement. Changing a filename from .json to .csv does not constitute a valid CSV export.
  • Character encoding must be UTF-8.
  • The filename must end in .csv.
  • The media type supplied during download or transfer must be text/csv.
  • The first record must contain the stable column headers listed below, in the listed order.
  • The second record must contain one complete Origin Passport data row for the exported batch.
  • Fields containing a comma, double quote, carriage return, or line break must use standard CSV quoting. Embedded double quotes must be escaped by doubling them.
  • Empty optional values must be represented as empty fields; columns must not be removed.

4. Data handling restrictions

The pilot file must be limited to the schema above. It must not contain negotiated cacao or supplier pricing, producer personal contact details, employee details, internal quality notes, employee comments, or credentials and system identifiers. Additional fields require written approval from Mapayça Retail Systems and Cocoarynth's data owner before transmission.

5. Submission and validation

  1. Create one CSV export for the production batch associated with the shipment.
  2. Confirm that the header row exactly matches the required schema, including spelling and order.
  3. Confirm that the product and batch identifiers match the shipment paperwork.
  4. Validate both date fields against the ISO YYYY-MM-DD pattern.
  5. Open the file with a CSV-aware parser and confirm that it produces exactly eleven columns.
  6. Transfer the file through the pilot channel identified in the shipment handoff.

6. Pilot acceptance criteria

A shipment passes traceability import acceptance when the delivered file:

  • is valid UTF-8 CSV and imports without manual conversion;
  • contains the exact header row and one data row;
  • identifies the Ecuador Esmeraldas 72% product and its production batch;
  • contains complete origin, producer, harvest, cacao percentage, certification, production date, and shipment date values;
  • uses ISO dates in both date columns; and
  • contains none of the prohibited confidential or personal information.
Clarification: Bulk export is not required for this pilot. A correctly formatted one-row CSV file for each exported batch is acceptable.

7. Change control

Column names and validation rules remain stable for the duration of the pilot. Proposed changes must be reviewed before a shipment file is produced. This document defines Mapayça's import contract; it does not describe or certify the current implementation of Cocoarynth Trace.
